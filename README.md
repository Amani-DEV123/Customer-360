# Customer 360° – Interactive Customer Report

## Overview
An interactive customer inquiry screen that allows users to search for a customer using their mobile number and view a comprehensive report containing the customer's information and related business activities.

## How It Works

1. **Customer Search:** Enter the customer's mobile number in the search field.
2. **Search Action:** Click the Search button to retrieve the customer's information.
3. **Customer Information:** Display the customer's details in an interactive report.
4. **Summary Cards:** Display four interactive cards showing the total number of records associated with the customer:

   - **Orders:** Displays the total number of orders registered under the customer's mobile number.
   - **Services:** Displays the total number of services associated with the customer.
   - **Sales Opportunities:** Displays the total number of sales opportunities associated with the customer.
   - **Complaints:** Displays the total number of complaints submitted by the customer.

5. **Detailed Reports:** Each card displays a dynamic count. Clicking on a card opens a detailed interactive report showing the related records for that customer.

## Key Features
- Search customers using their mobile numbers.
- View customer information in one place.
- Interactive dashboard with four summary cards.
- Dynamic record counts for each category.
- Drill-down functionality to view detailed reports.
- Customer-centric view of orders, services, sales opportunities, and complaints.

## Technologies
- Oracle APEX
- Oracle Database
- SQL / PL/SQL
- Interactive Reports
- JavaScript

## Objective
To provide a centralized customer view that enables users to quickly access customer information and track all related activities through a single interactive screen.
